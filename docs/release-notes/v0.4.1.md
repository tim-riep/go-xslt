go-xslt 0.4.1 makes XSLT 3.0 maps, arrays, grouping and typed function calls much faster, gives the source document its own URI, reports misplaced XSD schema children with a position, judges XML names by the XML 1.0 5th edition everywhere, speaks 28 languages in the desktop tester, and documents every third-party license from one generated source. Every W3C conformance number is the same as in 0.4.0.

## Engine

- **XSLT 3.0 paths that were quadratic are now linear.** `map:put` shares structure with the map it builds on (a persistent hash trie), so accumulating a map one entry at a time in `xsl:iterate` or `fold-left` no longer copies the whole map: 5,000 keys over 20,000 records took 53 s and now take 0.4 s. `array:append` appends in place to a shared backing array (35 s → 2 s for one entry per record over a 37 MB document). `xsl:for-each-group group-by` files its groups by key instead of comparing every item with every group (5× faster with 5,000 groups). Insertion order, key replacement and all results are unchanged.
- **Typed parameters and built-in calls allocate less.** A declared `as` type is parsed once and shared; a value that already matches a built-in atomic type is bound without building an evaluation context; built-in functions atomize their arguments without an intermediate item list; `round()` at precision 0 no longer goes through big rationals (bit-identical results, tested on 200,000 random doubles). A transform made of function calls runs 12 % faster with 24 % fewer allocations.
- **The source document has its own URI.** `Request.SourceURI` and `TransformRequest.SourceURI` (a path or a URI) become the source document's `document-uri()` and `base-uri()`, so relative references taken from the source (`document(@href, /)`, `resolve-uri(…, base-uri(/))`) resolve beside the source file even when the stylesheet lives elsewhere; `BaseDir` stays the stylesheet's base. The command line sets it to the source file's absolute path (not for stdin), the desktop tester to the run's source file. Without a source URI, `document-uri(/)` is now the empty sequence instead of a directory, while `base-uri()` keeps `BaseDir` as before. (#20)
- **XML names follow the XML 1.0 5th edition everywhere.** The parser, `xsl:element`/`xsl:attribute`/`xsl:namespace`/`xsl:processing-instruction` and `castable as xs:NCName` now agree: an emoji, a Bengali digit or any other 5th-edition name character is accepted as a name, and `<😀/>` parses. The tokenizer itself is unchanged; a document that parsed before costs nothing extra. (#23)

## XSD validation

- **A misplaced child of a complex type is a schema error with a position.** An `xs:assert`, `xs:openContent`, attribute or model group placed beside `xs:simpleContent`/`xs:complexContent` used to be accepted and silently ignored, so every instance passed the assertion; it is now rejected as `s4s-elt-invalid-content.1` with the schema line and column, as is a `simpleContent`/`complexContent` with zero or two derivations. Schema-for-schemas errors in general now name the line and column of the offending element. (#22)

## Desktop tester

- **28 interface languages.** Besides English, German, French and Italian, the tester now speaks Spanish, Portuguese, Dutch, Polish, Czech, Swedish, Danish, Norwegian, Finnish, Russian, Ukrainian, Turkish, Greek, Romanian, Hungarian, Japanese, Chinese (Simplified and Traditional), Korean, Arabic, Hebrew, Hindi, Indonesian and Vietnamese. "System" follows your computer's language, including regional and script variants (zh-TW lands on Traditional Chinese, nn on Bokmål). Only the language in use is loaded. Arabic and Hebrew lay the interface out right to left; the code editors and the output stay left to right.

## Licensing

- **Every third-party license has one source.** The dependency manifests (the Go modules compiled into each binary, the frontend's production packages) plus one small hand-kept file generate the app's Licenses view, `NOTICE` and a new `THIRD-PARTY-LICENSES.md`; CI fails when a shipped dependency is undocumented or the generated files are stale. This added the missing notices for `@codemirror/lang-json`, `@lezer/json`, the Unicode Character Database behind the regex block tables, the Go standard library and the `math.Exp` copy, and fixes the Linux package metadata, which said MIT instead of Apache-2.0. Releases now carry `LICENSE`, `NOTICE` and `THIRD-PARTY-LICENSES.md` next to the binaries.
